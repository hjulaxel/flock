## Watch the right edge

One mark per row, and three things earn one:

- **Amber** — this session is working right now.
- **Red** — it finished while you were elsewhere and you have not looked yet.
  Like an unread message, it clears the moment you focus the session.
- **Purple** — a compaction. A hollow ring while it runs, a filled dot once it
  has settled. It has a colour of its own because neither of the others was
  true of it: compaction is the one thing a session does that is neither work
  you asked for nor a question for you, and before this it wore both costumes
  in turn — amber while it ran, then red when it stopped. The dot clears when
  you open the session, because opening it is reading the note.

Everything else draws nothing. An idle row is bare and a closed one is dimmed,
because a column of marks nobody needs is a column the eye learns to skip.

The red dot rolls up onto the project row, so a collapsed project still tells
you there is something to come back to. The number on the sidebar icon counts
something else — the sessions **running** on this machine, in every window — so
a count you did not expect is a process you did not know about.
