## Watch the right edge

One mark per row, and only two states ever draw it:

- **Amber** — this session is working right now.
- **Red** — it finished while you were elsewhere and you have not looked yet.
  Like an unread message, it clears the moment you focus the session.

Everything else draws nothing. An idle row is bare and a closed one is dimmed,
because a column of marks nobody needs is a column the eye learns to skip.

The red dot rolls up onto the project row, so a collapsed project still tells
you there is something to come back to, and the badge on the sidebar icon counts
exactly the red dots on screen.
